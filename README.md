# Weatherly

Weatherly adalah dashboard cuaca berbasis web. Cari nama kota untuk melihat kondisi cuaca saat ini, atau simpan beberapa kota agar lebih gampang dipantau.

## Fitur
- Pencarian cuaca berdasarkan kota.
- Informasi suhu, kondisi cuaca, kelembapan, angin, tekanan udara, dan tutupan awan.
- Waktu matahari terbit dan terbenam.
- Pilihan Celsius dan Fahrenheit.
- Lokasi perangkat, jika izin lokasi diberikan.
- Riwayat pencarian dan daftar kota favorit.
- Halaman forecast dan insights.
- Opsi instalasi sebagai web app melalui PWA.

## Sumber data
- OpenWeather untuk data cuaca.
- BMKG sebagai referensi informasi dan peringatan cuaca Indonesia.

## Menjalankan
Clone repository lalu buka melalui local server.

~~~bash
git clone https://github.com/ahmadfas213-cell/Weatherly.git
cd Weatherly
~~~

Weatherly membutuhkan API key OpenWeather. Siapkan API key sendiri dan gunakan pada konfigurasi di script.js. Jangan unggah API key pribadi ke repository publik.

## Teknologi
HTML, CSS, JavaScript, OpenWeather API, dan PWA.
