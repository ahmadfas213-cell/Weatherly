INSTALL APP

Browser yang mendukung PWA bisa memasang Weatherly sebagai aplikasi standalone.

Android: buka menu browser lalu pilih Install app atau Add to Home screen. iPhone/iPad: buka lewat Safari, tekan Share, lalu Add to Home Screen. Windows: gunakan Install dari Chrome atau Edge. macOS: Safari 17+ mendukung Add to Dock.

SHARE

Kirim link Weatherly ke teman atau grup.

ALERTS

Aktifkan izin notifikasi browser untuk pengalaman alert di browser yang mendukungnya.
